# 官方资料与语音采集

目标：把角色的皮肤、语音、人设三样东西查全，而且每条都能回到来源。

## 一、先确认角色

同名角色很常见。先定作品，再定官方写法。

- 游戏官网的角色页最稳。看立绘、编号、阵营、CV。
- 官方微博和 B 站官方号发过角色 PV 和皮肤 PV，标题里通常带官方全名。
- TapTap 的「档案室」和微信公众号会发装束公告，包含装束名和专属台词。
- 海外 IP 看官方 X、官网 News 和 Fandom。

记录：角色名、编号、CV、阵营、上线时间。

## 二、皮肤清单

按发布时间排，逐条记：

- 官方皮肤名，不要用系列名代替。
- 系列名单独一列，比如「邂逅之钥系列」和「深廊引蝶」是两个层级。
- 获取方式：商城、活动、赠送。
- 官方图来源链接。
- 有没有官方 Q 版。

查法：

- `站点:wiki.biligame.com <作品> 皮肤图鉴`
- `<作品> <角色> 装束`
- 官方号的「禁闭者装束」合集
- 皮肤的语音页常常单独存在，页面名是「语音:角色名 皮肤名」

皮肤页里的「获得装束」「问候」「普通触摸」「闲置」「摸头」就是最贴近陪伴场景的原话，优先抓这几类。

## 三、语音采集

优先级从高到低：

1. 官方游戏内语音页，BWIKI 或 Fandom 的「语音:角色名」。
2. 官方皮肤语音页，通常是「语音:角色名 皮肤名」。
3. 官方 PV、角色展示视频的台词。
4. 二创整理，只用来补漏，标注来源。

抓这些字段：

- 获得角色、升阶、问候、交谈、特殊交谈。
- 闲置、烦躁、特别关注、服从度升满。
- 摸头、普通触摸一到四。
- 派遣、派遣完成、升级。
- 战斗开始、胜利、失败、必杀、死亡。战斗语音可以不用，但有助于理解她的说话方式。

整理成三组：

- 基础皮肤。
- 每套皮肤各自的触摸与问候。
- 通用台词，可以给所有皮肤用。

原话不要改字。需要断句时用省略号，不改词。

## 四、二创资料

官方资料补齐人设骨架，二创资料补细节。主战场是小红书和抖音，B 站、LOFTER、知乎补充。

| 平台 | 搜什么 | 拿什么 |
|---|---|---|
| 小红书 | `<角色> AI` | 出图提示词、画风锚点、配色 |
| 小红书 | `<角色> 冷知识` | 习惯、口癖、小设定 |
| 小红书 | `<角色> 分析` | 性格结构、关系 |
| 小红书 | `<角色> 剧情`、`<角色> 故事` | 时间线、创伤点 |
| 小红书 | `<角色> 台词`、`<角色> 语音` | 语气、名场面 |
| 抖音 | `<角色> 剧情解析` | 剧情梳理、动机 |
| 抖音 | `<角色> 台词向` | 高频台词、语气 |
| 抖音 | `<角色> 角色分析` | 性格判断 |
| 抖音 | `<角色> 混剪` | 画面、氛围 |
| B 站、LOFTER、知乎 | `<角色> 考据` | 长文、争议点 |

做法：

- 至少三个来源对得上才写进人设卡。
- 和官方冲突时以官方为准，冲突点单独记。
- 来源链接存进 `CHARACTER.md`。
- 二创只当参考。不要整段照搬，按角色语气重写，再过 `references/deai.md`。
- 涉及剧透的，标出剧透范围，不要写进开场白。

## 五、官方图下载

技能包不带角色图。开工时把官方立绘下载到项目的 `assets/refs/`。

- 来源：官网角色页、官方微博、B 站动态、TapTap、BWIKI 皮肤页、官方小红书。
- 每套皮肤至少一张全身立绘和一张面部特写。优先无水印、分辨率高的。
- 命名：`<皮肤key>_full.jpg`、`<皮肤key>_face.jpg`。皮肤 key 用英文，和 `SKINS` 一致。
- 下载后检查：角色对不对、皮肤对不对、脸有没有被裁、有没有水印。
- 来源链接写进 `CHARACTER.md`。
- `assets/refs/` 不参与运行。交付时可以不打包，公开仓库不要放。

```bash
mkdir -p assets/refs
curl -L -o assets/refs/vow_full.jpg "<官方图地址>"
```

## 六、记录格式

`CHARACTER.md` 里按这个结构写：

```markdown
## 皮肤
| 官方名 | 系列 | 上线 | 来源 | 官方Q版 |
## 语音
| 类别 | 原文 | 来源 |
## 人设
## 语言风格
## 边界
```

交付时这份文件跟着站点一起留下。
