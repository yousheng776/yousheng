# 豆包出图

豆包负责两件事：每套皮肤的 Q 版动作表情，四间陪伴场景。

官方图只做参考，站点里用豆包生成的图。官方图在项目里现场下载，放 `assets/refs/`，技能包不附带角色图。出图不是点一下就好，每一步都要对照官方图核对。

## 一、准备

- 每套皮肤一张官方全身立绘，一张面部特写，一张服装细节。
- 同一套皮肤的 Q 版参考，有就放进来。
- 角色配色：发色主色、高光、阴影、瞳色、肤色。
- 图片放进 `assets/refs/`，按皮肤命名，只做对照，不参与运行。

打开豆包桌面端，新建对话。先上传参考图，再说话。

## 二、先让它看懂

上传该皮肤的官方立绘和面部特写，发：

> 先看这几张图。用一句话描述画风、线条、上色方式、头身比。不要夸，只说特征。

它描述完，对照官方图检查。发型、瞳色、服装识别点、配饰、头身比，少一项就补一句：

> 再看一遍。头发是长直发还是卷发，眼睛什么颜色，衣服上有哪几个识别点，头身比大概几头身。

它看懂了再出图。看不懂就继续描述，不要急着生成。

## 三、每套皮肤要出什么

每套皮肤单独出，不借用别的皮肤的姿态。

八种表情：

`calm` 平静、`smile` 微笑、`shy` 害羞、`joy` 雀跃、`sad` 低落、`surprised` 惊讶、`sleepy` 困倦、`frenzy` 特殊状态。

至少三个动作，按人设选：

`bow` 行礼、`pray` 祈祷、`wave` 招手、`sit` 抱膝坐、`organ` 弹琴、`letter` 递信、`dessert` 端甜品、`stars` 数星星、`doll` 抱娃娃。

一个动作一张图。不要让它出一张九宫格，切不开，表情也会互相污染。

每张都必须同一张脸、同一套发型、同一套服装、同一个头身比、同一套配色。

## 四、提示词

提示词里不写作品名，不写角色名。用「这张图的角色」「参考图」指代。写了作品名和角色名，豆包容易回「暂时无法生成」。

表情：

> 照着这张图的角色，画一张二头身 Q 版全身立绘。保留长直发、金色眼睛、黑色蕾丝颈饰、白色婚纱和珍珠头纱，脸型和神态像原图。表情平静，双手捧着红玫瑰，站姿。细线，柔和赛璐璐上色，纯白背景，不要文字水印。

动作：

> 照着这张图的角色，画一张二头身 Q 版全身立绘。保留同一张脸、同一套发型、同一套服装和配色。她双手合十祈祷，眼睛闭着。细线，柔和赛璐璐上色，纯白背景，不要文字水印。

换皮肤时，把服装识别点换掉，脸和画风不变。

## 五、核对

每张出来，对照官方图逐项看：

| 项 | 看什么 |
|---|---|
| 发型 | 长度、分缝、刘海、发饰 |
| 瞳色 | 颜色、眼型、眼神 |
| 服装 | 领口、袖子、裙摆、层次、配色 |
| 配饰 | 颈饰、头纱、手套、鞋、挂件 |
| 头身比 | 二头身还是三头身，头和身体的比例 |
| 表情 | 是否和要的情绪一致，不要每张都笑 |
| 动作 | 手的位置、身体朝向、脚有没有被裁 |
| 背景 | 纯白，没有文字、水印、第二个人 |

不对就改具体位置：

> 这张比例可以，改三处。头发改成长直发，侧分刘海，不要双马尾。外套改成白色长风衣、红色内衬。眼睛半垂，不要这么幼。保持全身站姿、纯白背景、二头身。

不要写「再像一点」「再精致一点」，它不知道该改哪里。

改完再核对一遍。通过才下载。

## 六、下载与处理

下载白底原图，通常是 1024×1536 或更大，右下角带「豆包 AI 生成」水印。

```bash
python3 scripts/process_ai.py 输入.png assets/char/<皮肤>_<姿态>.png 96 assets/faces/<皮肤>.png
```

脚本会去白底、裁掉水印区、缩到 640×935 透明 PNG，再裁一张 360×360 头像。需要 Pillow 和 numpy，没有就 `pip install pillow numpy`。

检查三处：

- 边缘有没有白边。
- 脚有没有被裁。
- 透明处是不是真的透明。

有问题回豆包重出，不要用修图硬补。

## 七、陪伴场景

四间室内：咖啡馆、图书馆、教室、家里。

先把 Q 版和官方立绘发给豆包，让它描述画风。再发：

> 照这两张图的画风，画一张 16:9 横版场景背景，画面里不要出现人物。深夜的咖啡馆：左侧一扇大窗，窗外深蓝夜色和模糊的城市灯光；右侧暖色木墙和三盏暖黄吊灯；画面下方三分之一是一张横贯画面的木桌，桌沿平直，铺米白色蕾丝桌布，桌上放着两只白瓷茶杯、一块草莓蛋糕、一支点燃的蜡烛、一本旧书，中间留出空位。干净深色勾线，平涂上色，柔和明暗渐变，暖黄灯光和冷蓝窗光对比，精致，安静，无水印无文字。

图书馆、教室、家里照这个结构换环境，桌子都放在下方三分之一，中间留空。

出图后核对：

- 杯子、书、蜡烛的数量和位置对不对。
- 有没有多出挂画、绿植、第二张桌子。
- 桌沿是不是平的，能不能横贯画面。
- 画面里有没有人物、文字、水印。

多了就让它删：

> 背景多出挂画、绿植和一张小桌子，桌上旧书也摊开了。按原设定重画，只留两只杯子、一块蛋糕、一支蜡烛、一本合上的书，中间留空，无人物无文字。

下载 2048×1152 原图，缩到 1600×900，存成 `room_cafe.jpg`、`room_library.jpg`、`room_classroom.jpg`、`room_home.jpg`。

接入时给场景加 `painted: true`，用同一张图做 `#stageFore`，裁掉上半，盖住人物下半身。桌沿高度按每张图量，写进 `clip-path`。

## 八、不能直接操作豆包时

把每张图的提示词写成清单，放进 `doubao_inbox/PROMPTS.md`，写清文件名和尺寸。让用户按清单出图，存进 `doubao_inbox/`。

图回来后：

- Q 版走 `scripts/process_ai.py`。
- 场景走 `scripts/apply_scenes.py <项目目录>`，裁成 1600×900 并压暗角。

预览确认后再接进页面。占位图不要留到交付。

## 九、验收

- [ ] 每套皮肤八种表情，至少三个动作。
- [ ] 每张都对照过官方立绘，发型、瞳色、服装、配饰、头身比一致。
- [ ] 没有借用别的皮肤的姿态。
- [ ] 透明底干净，脚完整，640×935。
- [ ] 四间室内都有 1600×900 背景，桌沿平，画面里没有人物和文字。
- [ ] 场景接进去后，人物坐在桌后，下半身被前景盖住。
- [ ] 运行时目录里没有官方参考图。
