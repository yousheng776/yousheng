# Q 版与素材规格

模板里的素材目录和文件名是固定的。换图不改代码，按名字覆盖即可。

## 一、目录

```
assets/
  char/      Q 版姿态和头像
  scenes/    场景背景
  faces/     方形头像
  refs/      官方参考图（不参与运行）
```

## 二、尺寸

| 用途 | 尺寸 | 格式 |
|---|---|---|
| 站姿 Q 版 | 640×935 | PNG 透明底 |
| 坐姿、睡姿 | 640×437 | PNG 透明底 |
| 方形头像 | 360×360 | PNG 或 JPG |
| 场景 | 1600×900 或 1440×1920 | JPG |
| 全身原画 | 1330×1773 | JPG |

透明底不要用 JPG，会带白底。场景不要用 PNG，体积大。

## 三、每个皮肤需要什么

基础八种：

`calm` 平静、`smile` 微笑、`shy` 害羞、`joy` 雀跃、`sad` 低落、`surprised` 惊讶、`sleepy` 困倦、`frenzy` 特殊状态。

动作按人设加，常用的有：

`bow` 行礼、`pray` 祈祷、`wave` 招手、`sit` 抱膝坐、`organ` 弹琴、`letter` 递信、`dessert` 端甜品、`stars` 数星星、`doll` 抱娃娃。

每套皮肤单独出一套，不借用别的皮肤的姿态。八种表情加至少三个动作，每张同一张脸、同一套服装、同一个头身比。每套皮肤至少一张全身原画或一张场景立绘，用来做静态皮肤。

## 四、画风锚点

同一套皮肤必须同一张脸、同一套配色、同一个头身比。出图前把这几条写进提示词：

- 作品画风，二头身或三头身，细线，柔和赛璐璐。
- 发色主色、高光、阴影三个色值。
- 瞳色。
- 皮肤底色。
- 服装识别点，三到五个，比如玫瑰、珍珠、蕾丝、蝴蝶、金饰。
- 透明底，全身，正面或微侧。

## 五、提示词

提示词里不写作品名和角色名。用「这张图的角色」「参考图」指代。完整模板和核对表见 `references/doubao.md`。

Q 版：

> 照着这张图的角色，画一张二头身 Q 版全身立绘。保留<发色与发型>、<瞳色>、<服装识别点>、<配饰>。<表情>，<动作>。细线，柔和赛璐璐上色，纯白背景，不要文字水印。

场景：

> 照这两张图的画风，画一张 16:9 横版场景背景，画面里不要出现人物。<时间>的<地点>，<三样环境元素>，桌子画在下方三分之一，桌上放<道具>，中间留空。干净深色勾线，平涂上色，柔和明暗，无水印无文字。

## 六、不能直接操作豆包时

把每张图的提示词、文件名、尺寸写成清单，放进 `doubao_inbox/PROMPTS.md`。让用户按清单出图，存进 `doubao_inbox/`。

图回来后：

- Q 版走 `scripts/process_ai.py`，去白底、裁水印、缩到 640×935。
- 场景走 `scripts/apply_scenes.py <项目目录>`，裁成 1600×900。

预览确认后再接进页面。占位图不要留到交付。

## 七、陪伴画面

两类，八套。

### 官方立绘

直接放 `assets/scenes/`，竖图 1330×1773。婚纱、幽庭、深廊、近景四套。近景靠 `object-position` 和 `scale` 裁。

### 室内空房间

`room_cafe.jpg`、`room_library.jpg`、`room_classroom.jpg`、`room_home.jpg`，1600×900。这四张可以直接用豆包生成：

1. 先把角色 Q 版和官方立绘发给豆包，让它描述画风、线条、上色。
2. 再让它照这个画风出 16:9 空房间，桌子画在下方三分之一，桌面放杯子、书、蜡烛。
3. 出图后逐张对照：多出的挂画、绿植、第二张桌子都让它删掉，它会自己修订。
4. 下载 2048×1152 原图，缩到 1600×900。
5. 接入用 `painted: true` 和 `#stageFore`，裁切线按桌沿调。

提示词里不要写作品名和角色名，用「这两张图的画风」指代。

- 画的时候留出中间站位，人物是后叠的 Q 版。
- 光线要暗，靠窗光和台灯做亮部，人物才站得住。
- 色调跟角色一致：暖棕、深绿、雾蓝、玫瑰灰。
- 底部留一条深色带，计时卡压在上面。
- 没有把握画好，宁可做暗调剪影，不要把家具画得太满。

### 桌子

带桌子的场景把桌子画进背景图。接入时给场景加 `painted: true`，用同一张图做 `#stageFore`，裁掉上半，盖住人物下半身。桌沿高度按图量，写进 `clip-path`。

旧版 `table_fg.png` 是 1600×900 透明 PNG，只做兜底。人物叠在桌子下面，桌沿挡住腰以下。

道具热区在 `#tableProps`，坐标按桌子图里的位置摆。
